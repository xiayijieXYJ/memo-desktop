Memo 使用说明
========================================

这是一个常驻桌面的小卡片，管「今天要做的事」，也能提前把明天、下周的事记下来。

怎么用
----------------------------------------
1. 把 Memo.exe 放到一个固定的地方，比如 C:\Tools\Memo\
   （不要放在桌面或下载文件夹，免得哪天顺手删掉）
2. 双击 Memo.exe 就能用，不需要安装，不需要装 .NET 运行库
3. 第一次启动后，Windows 可能弹「已保护你的电脑」——
   点「更多信息」→「仍要运行」即可（因为没有买代码签名证书）

常用操作
----------------------------------------
- 加一条：在顶部输入框打字，回车
- 改优先级：点条目左边的「高/中/低」徽章，三档轮换
- 改文字：双击条目文字，回车保存（字多的会自动换行，框跟着长高，卡片大小不变）
- 完成：点前面的圆圈，会划掉并移到底部
- 删除：在条目上点右键 →「删除」；删错了点底部「撤销」
- 月度总结：点卡片底部「月度总结」，或右键菜单里「月度总结…」
- 唤出/收起：Ctrl + Alt + M（在任何程序里都生效）
- 隐藏到托盘：点右上角 — 或 ✕，任务栏不会有图标
- 设置：右上角齿轮，或在卡片空白处右键
- 拖动窗口：主卡片、设置窗、日历小窗都可以按住空白处拖走，
  按钮/滑块/日期格子照常点，不会误拖
- 换主题：设置里最上面一行有「深色 / 浅色 / 浅黄」三个胶囊，
  点一下立即生效。选好之后重开还是那个样子，不用每次调

右键菜单里还有什么
----------------------------------------
卡片空白处右键：
  设置… / 添加一条 / 清除已完成 / 显示或隐藏已完成 / 隐藏到托盘
条目上右键：
  编辑 / 复制文字 / 高优先级 / 中优先级 / 低优先级 / 删除

底部不再有「清除已完成」「显示已完成」按钮，都收到右键菜单里了——
卡片宽度有限，底部只留状态文字和「撤销」。

跨天和查看以前的记录
----------------------------------------
没做完的事第二天照样在，会标一行「顺延N天」。
昨天做完的事当天就不再显示了（数据还在，能回看）。
有一种情况例外：以前几天记下、今天才勾掉的事，勾掉后当天仍留在卡片上（划线、沉到底部），
到第二天才退出——否则一勾就当场消失，容易以为数据丢了。

回看以前的记录：
- 点标题旁的 ‹ › 箭头，前一天 / 后一天，随便翻，翻到没记录的日子会显示「这天没有记录」
- 点 📅 打开日历，直接挑日子，有记录的日子带蓝点
- 看历史时是只读的，不能增改；点「回到今天」回到现在

提前安排将来要做的事
----------------------------------------
- 往后翻：点「›」箭头，或者点 📅 在日历上挑将来某一天
- 顶上会显示「安排 10月21日」，输入框提示变成「提前记下 10月21日 要做的事…」，
  加进去的事就记在那一天
- 当天做的事不会提前冒到今天：明天的安排今天看不到，到了那天自动出现在今天的列表里
- 将来的日子和今天一样能加、能勾完成、能改优先级（只有翻看过去时才只读）
- 想回到今天点「回到今天」，或把箭头往回翻到今天就自动恢复了

箭头可以一直往前翻到很早以前，也可以往后翻安排将来。

看看这个月干了什么
----------------------------------------
点卡片底部的「月度总结」，或右键菜单里「月度总结…」，会弹出一个小窗：

- 顶部三个数字：本月完成 / 本月新增 / 仍在处理
- 「本月完成」那一栏是按「哪天勾掉的」算的：
  9 月安排、10 月才做完的事，算进 10 月，不算 9 月
- 「仍在处理」那一栏是眼下所有没做完的事，不按月份分，
  拖过日子的会标「顺延N天」，放在将来某天的也会列出来
- 左右箭头 ‹ › 翻上个月 / 下个月，点「回到本月」跳回现在
- 想抄走某条（比如单号、任务原文），双击那一行就复制到剪贴板了，
  标题旁边会闪一下「已复制」
- 想关掉点右上角 ✕，或按 Esc

小窗可以按住空白处拖走，看完不影响卡片继续用。

开机自启
----------------------------------------
设置窗口里勾上「开机自启」即可，不需要管理员权限。
注意：如果你之后挪动或改名了 Memo.exe，要重新勾一次，
否则开机启动会指向旧路径。

你的数据在哪
----------------------------------------
%APPDATA%\Memo\
  memo.db        所有待办
  settings.json  窗口位置、透明度等
  backups\       每次启动自动备份，保留最近 20 份

数据只存在你自己电脑上，不联网、不上传。
换电脑时把整个 Memo 文件夹拷过去即可。

卸载
----------------------------------------
1. 先到设置里取消「开机自启」
2. 退出程序（托盘图标右键 → 退出）
3. 删掉 Memo.exe 和 %APPDATA%\Memo 文件夹
（删 %APPDATA%\Memo 会连数据一起没，想留数据就先拷走 backups）
